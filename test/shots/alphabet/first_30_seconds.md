## The first 30 seconds (written before the code)

**Phone, first visit.** The page opens on the game: no menu, no Start button, no modal. The clock reads a dim 0.00; the pill under it
reads "Goal: under 14 s" (the first rank), and "Best 6.75" once there is a best to beat. A giant red-marked **A** waits with B C D fading under it and one line, "Tap A to start". The keyboard is
the page's own, in the thumb zone, with 10 keys across (every tap in a gap counts for the nearest key).
- **Nothing touched for 1.4 s:** the A key pulses red. That is the only help the game ever gives and it only comes when it is needed.
- **Tap A:** the clock wakes and starts the same frame (the first key *is* the start; the A key inks, a note sounds, the A is
  stamped into the first segment, the hero becomes B). The caption fades, the mode switch greys out so a run cannot be
  changed halfway. The player learns the whole game from this one tap: letters go in the bar, the pitch goes up.
- **Tap any other key before A:** the hero shakes, the key flashes red, nothing starts and nothing is counted.
- **First mistake:** the wrong key and the big letter hold vermilion and shake, the brackets flash, a dull thock breaks the climb,
  the clock keeps running (the mistake costs exactly the time spent finding the right key — there is no other penalty). It is
  counted as a slip and shown at the end, not during.
- **Stall for 1.4 s:** the next key pulses.
- **Z:** the clock freezes (to the hundredth, from the key timestamps rather than the frame clock), the clock thumps, a V-I chord
  rings; 240 ms later the result sheet slides up over the bar and the keyboard: the rank stamp, "0.87 s from Foreman · clean run",
  your history on this board as a chart (higher is faster) with a one-line trend, a thin per-letter strip, and AGAIN (focused, Enter or Space works) next to SHARE. Taps that
  are still landing in the first half second do nothing, so a thumb still hammering cannot restart the game by accident.
- **Again:** straight back to the first letter. Escape or the restart icon abandon a run at any time. Leaving the tab during
  a run cancels it (the clock would otherwise count time away).

**Desktop.** Same page; the on-screen keyboard mirrors the real one (keys ink as you type) and lights the hint key. Keys are
read by letter, falling back to physical position for non-Latin layouts.

**Screen states and the way through them.** `ready` (load, Again, Escape, restart, mode switch) → `run` (first right key) →
`done` (last right key) → `ready`. `run` → `ready` by Escape, restart or leaving the tab. Modes (Forward, Reverse, Daily) can be
changed in `ready` and `done` only.

**Tomorrow.** The Daily tab wears a red dot until today's board has been played. Daily is a shuffled alphabet that is the same on
every device that day, fair by construction (finger travel within 7 % of the mean, no step that runs on to the next letter, so no
day is a lucky one), with a streak and a share line that gives none of the board away. Bests are kept per board (and the daily
best per day); the blue triangle and the gap pill race the best run letter by letter. A player of the old page finds their best
Forward and Reverse times and ghosts, and their mute choice, carried over.
