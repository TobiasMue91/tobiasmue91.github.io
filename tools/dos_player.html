C:\> DOS Player

Play the DOS games you own, from your own disk. Everything runs locally in DOSBox - your files are never uploaded.

Drop files here or click to choose CD images (.iso, .cue + .bin), a game folder as .zip, or a single .exe / .com
    How the drives are set up

    A ZIP is unpacked onto C:, together with any loose EXE/COM files. CD images become drive D: (more than one: D:, E:, ...). For a CUE sheet, add the .bin/.wav tracks it lists too - then CD audio works. Games that want to install themselves can install from D: to C:.

    The emulated disk lives in memory, so installs and save games are gone when the page is closed - use the js-dos menu to save state if you need to. Large CD images need as much free RAM as they are big. Emulation by js-dos (DOSBox, GPL).
