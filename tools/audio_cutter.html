Advanced Audio Cutter

Upload, create multiple selections, rearrange, and export your audio

How to use:

  • Upload an audio file using drag & drop or the file selector
  • Click and drag on the waveform to select the parts to keep
  • Zoom in, or type a start and end time, to place a cut exactly (↑/↓ nudges by 10 ms)
  • Create multiple selections and rearrange their order
  • Use the "Create Final Audio" button to combine all regions - the joins are crossfaded so they don't click
  • Download the result as a new audio file
